Code Review Overview

Before beginning the three CS 499 artifact enhancements, I completed a code review of my CS 330 Star Trek battle scene. The purpose of the review was to examine the existing application, identify areas for improvement, and establish the enhancement plan used throughout the capstone.

The review examines the artifact in the areas of software design and engineering, algorithms and data structures, and databases. It discusses the existing functionality, limitations in the original implementation, and the improvements planned for each category.

Recorded Code Review

Enhancement Categories

The code review established three related enhancements for the artifact:

Software Design and Engineering: Refactor the application toward a more modular, data-driven architecture and improve resource management and defensive programming.

Algorithms and Data Structures: Replace fixed photon torpedoes with dynamic projectile behavior and implement spatial-grid collision detection.

Databases: Integrate SQLite to persist scene entities, scenes, and camera configuration data.
